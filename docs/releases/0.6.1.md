# wfwatch 0.6.1 – grouped CLI subagents

Codex and OpenCode sessions launched by a Codex agent now appear beneath their parent instead
of as duplicate top-level sessions. Orca-created Codex chats are linked using its local native-ID
mapping. Links require exact session identities; a shared project directory is never sufficient.

The patch also handles redirected output and Windows file URIs. Regression tests cover nested
agents, repeated scans, completion, missing parents, changed transcripts, conflicting links and
unavailable Orca databases. Unsupported wrappers and launches without verifiable identities
remain separate.

## Update

```sh
uv tool install --force 'git+https://github.com/zamirka/wfwatch.git@v0.6.1'
```

Restart an already running monitor after updating. Existing plans and agent configuration are
preserved. To roll back, install the same URL with `@v0.6.0`.

for the regression matrix and implementation boundaries.

acceptance, Ruff and strict Twine metadata validation passed. Distribution files and checksums
